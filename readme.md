# BOTUN AMACI 
## ban bot 
bu bot kullanıcıları banlamak ve eğlenemk için tasarlanmıştır 
botu kullanabilmek için "//ban @username" kullanılmalıdır
botun çalışdığını denemek için "//merhaba" veya "//about" yazabilirsiniz
kumar komutları için şu komutları kullanın : "//cf" yazı tura için ,örnek olarak 6 yüzlü 2 zar atmak için "//2d6" yazabilirsiniz 
Zar sayısı 1-100, zar yüzü 1-1000000 arasında olmalıdır
